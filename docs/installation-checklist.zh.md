# 鸿蒙与安卓安装验收清单

本清单用于安装交付和故障复测。每项都应由实际状态或一次真实操作证明，不要
仅凭“已经安装”判断成功。

## A. 通用电脑端

- [ ] 电脑浏览器能打开 `http://127.0.0.1:3080/`。
- [ ] Harness 显示使用者原来的工作区和会话。
- [ ] Windows Tailscale 已登录使用者自己的账号并显示在线。
- [ ] `tailscale serve status` 显示 `tailnet only`。
- [ ] Serve 目标为 `http://127.0.0.1:3080`。
- [ ] 没有启用 Funnel，没有路由器公网端口映射。
- [ ] `scripts\test-windows-readiness.ps1` 输出 `RESULT=READY`。
- [ ] 电脑已设置为远程使用期间不自动休眠。

## B. 安卓手机

- [ ] 安装的是官方 Tailscale Android 应用。
- [ ] 手机和电脑登录同一个、由使用者自己拥有的 Tailscale 账号。
- [ ] 已允许系统创建 VPN。
- [ ] 已允许移动数据、后台数据和后台活动。
- [ ] 测试期间已关闭其他 VPN、代理或网络加速器。
- [ ] Tailscale 中能看到自己的 Windows 节点在线。
- [ ] Edge 或 Chrome 能打开电脑的 `https://...ts.net/` 地址。
- [ ] 能看到电脑原来的工作区和会话。
- [ ] 关闭 Wi-Fi 后，通过移动数据仍能打开页面。
- [ ] 手机发送 `ANDROID_REMOTE_OK` 后，电脑端出现同步消息和回复。

## C. HarmonyOS 手机

- [ ] 已安装本地签名 HAP，并完成首次 USB 调试授权。
- [ ] 应用和电脑登录同一个、由使用者自己拥有的 Tailscale 账号。
- [ ] 已允许 HarmonyOS 创建 VPN，顶部出现 VPN 图标。
- [ ] 已允许应用后台运行，并避免系统一键清理。
- [ ] 浏览器能打开电脑的 `https://...ts.net/` 地址。
- [ ] 首次加载等待约一分钟后能看到原工作区和会话。
- [ ] 手机发送短消息后，电脑端出现同步消息和回复。
- [ ] 拔掉 USB、改用移动数据后仍能完成消息往返。

## D. 安全交付

- [ ] 使用者没有收到或使用仓库作者的 Tailscale 登录信息。
- [ ] 文档、截图和日志不包含真实 IP、机器名、登录链接或认证密钥。
- [ ] 没有公开 API Key、`.credentials.yaml`、`DSH_HOME` 或聊天记录。
- [ ] 使用者理解 Harness 具有电脑文件和命令执行能力。
- [ ] 手机设置了锁屏，Tailscale 账号建议开启两步验证。

## E. 验收等级

| 级别 | 必须提供的证据 | 结论 |
|---|---|---|
| L0 | 应用已安装 | 尚未证明网络或 Harness 可用 |
| L1 | VPN 已连接且手机能打开 Harness 首页 | 私网与 Serve 基本可用 |
| L2 | 手机能看到原工作区和会话 | 会话读取链路可用 |
| L3 | 手机发消息，电脑同步并返回回复 | 远程控制链路完成 |
| L4 | 拔 USB、关闭 Wi-Fi、重连后仍通过移动数据完成 L3 | 日常远程使用验收完成 |

最终交付目标是 L4。安卓从一开始就不依赖 USB；HarmonyOS 的 USB 只用于首次
安装、覆盖安装和调试。
