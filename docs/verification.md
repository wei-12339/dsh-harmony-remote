# 验证清单

面向安装交付的双平台完整版本见
[鸿蒙与安卓安装验收清单](installation-checklist.zh.md)。

## 电脑端

- [ ] Harness 桌面页面可以打开原工作区。
- [ ] `tailscale status` 显示 Windows 节点在线。
- [ ] `tailscale serve status` 显示 `tailnet only`。
- [ ] Serve 目标是 `http://127.0.0.1:3080`。
- [ ] 没有启用 Funnel 或公网端口映射。
- [ ] `scripts\test-windows-readiness.ps1` 输出 `RESULT=READY`。

## 手机端

- [ ] Tailscale 账号与电脑相同。
- [ ] 点击连接后顶部出现 VPN 图标。
- [ ] 连接偶发失败时，退出后再次连接可恢复。
- [ ] Edge 首次进入等待约 1 分钟后能显示页面。
- [ ] 页面可以显示原工作区。
- [ ] 页面可以进入原会话。
- [ ] 发送短消息后电脑端出现同步事件。

### Android 补充

- [ ] 使用官方 Tailscale，而不是来源不明的第三方 APK。
- [ ] 关闭其他 VPN 后完成首次连接。
- [ ] 允许移动数据和后台活动。
- [ ] 关闭 Wi-Fi 后通过移动数据完成一次消息往返。

### HarmonyOS 补充

- [ ] 首次 HAP 安装和 VPN 授权完成。
- [ ] 拔掉 USB 后仍能通过移动数据完成一次消息往返。

## 结果分级

| 级别 | 证据 | 结论 |
|---|---|---|
| L0 | 只有应用显示“已连接” | 仅证明 UI 状态，不能证明网络可用 |
| L1 | 手机能打开 Harness 首页 | 私网和 Serve 基本可用 |
| L2 | 能看到原工作区和会话 | 会话读取链路可用 |
| L3 | 手机发消息、电脑同步并回复 | 远程控制链路完成 |
| L4 | 重连、拔 USB、移动数据下仍可用 | 日常运行验证完成 |

不要把“安装成功”或“页面打开”误认为 L3/L4 级验证。
