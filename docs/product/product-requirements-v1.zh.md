# V1 产品需求文档

状态：已确认的建设基线

范围：Windows 一键安装器、安全网关、Android/HarmonyOS 客户端、兼容性计划

## 1. 产品愿景

让非专业用户能够在不开放公网端口、不迁移原工作区和聊天记录的前提下，用
自己的手机安全地连接自己的 Windows 电脑，查看 DeepSeek Harness 会话、发送
任务、确认风险操作、查看执行状态，并在异常时立即断开或停止远程入口。

## 2. 目标用户

### 主要用户

- 已经在 Windows 使用 DeepSeek Harness，希望用手机远程继续任务的个人用户。
- 使用 Android 或 HarmonyOS，缺乏命令行和网络配置经验的普通用户。
- 需要为少量团队成员部署受控远程入口的技术管理员。

### 用户前提

- 用户拥有并管理自己的 Windows 电脑和 Tailscale 账号。
- 用户理解 Harness 可能读写工作区并执行工具。
- 电脑关机或休眠时，手机不能继续控制本机 Harness。

## 3. 产品模式

### Managed Gateway Mode，产品默认

手机只连接 Windows 本地安全网关。网关完成设备绑定、会话认证、策略判断、
审计、限流和紧急停止，再通过 Harness Adapter 访问本机 Harness。

### Legacy Bridge Mode，兼容模式

保留当前 Tailscale Serve 直接代理 Harness 的方式，用于迁移、诊断和旧设备。
该模式缺少产品级独立认证和细粒度策略，界面必须明确显示“兼容模式”。

## 4. V1 成功标准

- 普通用户在 10 分钟内完成 Windows 安装与手机绑定，不手工编辑配置文件。
- 安装失败时不破坏原 Harness、原工作区、会话或 Tailscale 登录状态。
- 默认不启用 Funnel，不开放路由器公网端口。
- 手机丢失后，用户可在电脑端一键撤销该设备。
- 用户可暂停所有远程访问，并在 5 秒内阻止新请求进入网关。
- 诊断信息能够说明故障发生在 Harness、Tailscale、网关、客户端还是系统后台。
- 兼容性上报默认关闭；开启后不采集提示词、聊天内容、文件内容、密钥和路径。

## 5. 核心用户旅程

### 5.1 首次安装

1. 用户运行已签名的 Windows 安装器。
2. 安装器只读检测 Harness、端口、Tailscale、系统版本和休眠策略。
3. 安装器展示计划修改项、备份位置和回滚方式。
4. 用户确认后，安装本地网关并配置 tailnet-only Serve。
5. 电脑显示一次性二维码和六位配对码。
6. 手机客户端生成设备密钥，扫描二维码并在电脑端确认设备名称。
7. 系统执行页面访问、会话读取和消息往返测试。
8. 验收通过后显示当前安全模式、远程地址和撤销入口。

### 5.2 日常远程使用

1. 手机连接自己的 Tailscale tailnet。
2. 客户端使用设备密钥向本地网关认证。
3. 用户选择已授权工作区和会话。
4. 用户发送任务，客户端显示实时状态和断线恢复信息。
5. 高风险动作在策略允许且底层可拦截时要求确认。

### 5.3 丢失手机或异常行为

1. 用户在电脑控制台暂停远程入口或撤销设备。
2. 网关立即拒绝该设备的新请求并关闭活动会话。
3. 审计日志记录撤销时间、设备和操作者，不记录聊天正文。

### 5.4 升级失败

1. 更新前验证发布签名和 SHA-256。
2. 保存上一版本二进制、配置和 Serve 状态快照。
3. 健康检查失败时自动恢复上一版本。
4. 回滚不得删除用户工作区、Harness 会话或 Tailscale 身份。

## 7. 非功能需求

### 安全

- 网关默认仅监听 `127.0.0.1`，由 Tailscale Serve 提供 tailnet-only HTTPS。
- Tailscale 是传输边界，不代替产品设备认证。
- 配对令牌一次性使用，默认 5 分钟过期。
- 长期设备私钥只保存在手机系统安全存储中。
- 日志和诊断不得包含 API Key、聊天正文、文件正文或认证令牌。

### 可靠性

- 重复安装应幂等；重复运行不能创建多个冲突 Serve 配置。
- 任一步骤失败都应标明阶段、错误码和建议恢复动作。
- 网关重启后应恢复已授权设备，但不恢复已过期会话令牌。
- 客户端重复发送同一个请求标识时，不得重复执行任务。

### 性能

- 电脑在线且网络正常时，网关健康检查应在 3 秒内返回。
- 本地策略判断和审计写入不应给普通请求增加超过 200ms 的目标开销。
- 移动端首次加载应采用分页和增量事件，避免一次读取完整长会话。

### 可维护性

- Android 与 HarmonyOS 共享协议、错误码和验收用例，不强制共享 UI 代码。
- Harness 集成通过 Adapter 隔离，避免把未稳定的上游接口扩散到客户端。
- 所有持久化格式必须包含 schema version。

## 8. 明确非目标

- V1 不提供公网匿名访问。
- V1 不托管用户聊天记录、工作区文件或 DeepSeek 凭据。
- V1 不承诺在未完成 Harness 接口调研前实现每一次工具调用的细粒度拦截。
- V1 不远程唤醒已关机电脑；Wake-on-LAN 可作为后续独立功能评估。
- V1 不通过共享作者账号为其他用户提供中心 VPN 服务。
- V1 不自动关闭 Windows 安全软件或放宽系统防火墙。

## 9. 发布门槛

安装器或客户端只有满足以下条件才能标记为公开测试版：

- 已通过全新安装、覆盖安装、失败回滚和卸载保留用户数据测试。
- 已通过 Funnel/公网暴露检查。
- 已通过手机撤销、令牌过期、重复请求和紧急停止测试。
- 已完成至少两个 Windows 版本、三个 Android 品牌和一个 HarmonyOS 版本测试。
- 已完成敏感信息扫描和第三方依赖许可证清单。

## 10. 实施前必须完成的调研

- 枚举 Harness 当前 HTTP、WebSocket、事件流和会话接口。
- 确认哪些操作可以在服务端可靠识别、暂停、拒绝和恢复。
- 明确 Harness 更新后接口兼容策略。
- 确认 Tailscale Serve 身份信息和本地 API 在目标版本上的使用边界。
- 选择 Windows 服务账户、配置目录和签名/更新机制。
