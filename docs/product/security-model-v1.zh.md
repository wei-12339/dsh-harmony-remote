# V1 安全模型

## 1. 保护对象

- Windows 用户账户和本机文件。
- Harness 工作区、会话、凭据和模型调用权限。
- 已绑定手机的设备身份。
- 网关策略、审计记录和更新通道。
- Tailscale tailnet 成员关系与 Serve 配置。

## 2. 威胁假设

- 远程地址可能被截图或转发。
- 同一 tailnet 可能存在不应访问 Harness 的其他设备。
- 手机可能丢失、被解锁或安装恶意应用。
- 攻击者可能重放配对码、请求或审批结果。
- 第三方依赖或更新包可能被替换。
- Harness 升级可能改变接口，导致策略失效。
- 用户可能误启用 Funnel、公网端口或宽松防火墙规则。

不在 V1 防护范围：Windows 管理员账户已被完全攻陷、内核级恶意软件、Tailscale
控制平面本身被攻陷。遇到这些情况，产品不能承诺保护 Harness。

## 3. 安全原则

- 默认拒绝：未知设备、未知能力和未知风险类型均拒绝或降级到只读。
- 双重边界：tailnet 成员身份加产品设备身份。
- 最小权限：安装器与运行时权限分离。
- 无内容遥测：兼容性系统不接收用户提示词、回复或文件内容。
- 可撤销：设备、会话、工作区授权和远程入口均可撤销。
- 可验证更新：发布签名、哈希、版本单调性和回滚保护。

## 4. 身份与会话

### 设备身份

- 每台手机生成独立密钥对。
- 私钥存储在 Android Keystore 或 HarmonyOS 等效安全存储。
- 网关只保存公钥、设备名称、创建时间、最后使用时间和权限。
- 设备撤销后，所有活动令牌立即失效。

### 配对

- 配对必须由电脑本机用户发起。
- 二维码/六位码一次性使用并短期过期。
- 最终绑定必须在电脑显示设备指纹后再次确认。
- 连续失败触发限流，不返回“账号存在”等可枚举信息。

### 会话

- 使用短期访问令牌和可撤销刷新机制。
- 令牌绑定设备公钥、网关实例和权限版本。
- 时钟偏差、重放和重复请求必须有明确处理。
- 手机生物识别只作为本地解锁增强，不能代替设备密钥验证。

## 5. 权限模型

建议 V1 权限：

| 权限 | 含义 |
|---|---|
| `status:read` | 查看电脑、网关和 Harness 状态 |
| `sessions:read` | 查看已授权会话摘要 |
| `messages:send` | 向已授权会话发送任务 |
| `approvals:resolve` | 允许或拒绝待确认操作 |
| `workspace:read` | 读取授权工作区范围内信息 |
| `workspace:write` | 允许可能修改文件的操作 |
| `gateway:stop` | 暂停远程入口或紧急停止 |
| `devices:manage` | 仅电脑本机控制台拥有 |

移动端不能获得 `devices:manage`，避免丢失手机继续添加其他设备。

## 6. 风险等级

| 等级 | 示例 | 默认策略 |
|---|---|---|
| R0 | 健康状态、版本、只读摘要 | 已授权设备可直接执行 |
| R1 | 读取会话、读取授权工作区元数据 | 记录审计，可按用户策略确认 |
| R2 | 发送可能触发工具的任务、修改工作区文件 | 任务级确认或策略确认 |
| R3 | 执行命令、删除/覆盖文件、安装软件、访问工作区外路径 | 必须明确确认，不能后台自动允许 |
| R4 | 修改安全策略、启用公网暴露、导出凭据 | 移动端禁止，仅电脑本机操作 |

只有 Harness Adapter 能可靠识别的动作才能做操作级审批。不能识别时必须显示
“当前为任务级控制”，不能宣称已经拦截每条命令。

## 7. 审计

审计记录允许包含：

- 时间、设备 ID、操作类型、风险等级、结果和错误码。
- 工作区别名、会话别名和策略版本。
- 批准/拒绝事件及批准设备。

默认不得包含：

- 提示词、模型回复、文件内容、命令完整参数。
- API Key、访问令牌、配对令牌、真实工作区路径。

如果后续提供“详细审计”，必须由用户单独启用并明确说明内容和保留期限。

## 8. 紧急停止

紧急停止分三级：

1. `Pause Remote`：网关拒绝新的远程请求，保留本机 Harness。
2. `Revoke All Sessions`：撤销所有手机令牌并断开活动连接。
3. `Stop Managed Task`：仅停止由网关明确创建和跟踪的任务。

网关不得默认杀死一个并非由它启动的 Harness 进程。停止用户现有 Harness 需要
电脑本机明确确认，并作为独立恢复动作处理。

## 9. 更新与供应链

- Windows 安装器、网关和客户端发布物必须签名。
- 更新清单包含版本、SHA-256、最小兼容版本和回滚版本。
- 客户端只信任固定发布公钥或平台商店签名。
- 禁止从 README 中的任意 URL 下载并执行未验证脚本。
- 依赖项生成 SBOM，并执行许可证与已知漏洞扫描。
- 发布流程不得把签名私钥、Tailscale auth key 或测试凭据写入仓库。

## 10. 主要威胁与控制

| 威胁 | 控制 | 验证 |
|---|---|---|
| URL 泄露 | tailnet-only + 设备认证 | 未绑定 tailnet 设备和未绑定产品设备均失败 |
| 配对码重放 | 哈希保存、一次性、短过期 | 第二次使用返回统一错误 |
| 手机丢失 | 设备撤销、短会话、系统安全存储 | 撤销后 5 秒内新请求失败 |
| 请求重放 | `request_id`、签名挑战、幂等缓存 | 重复请求只执行一次 |
| Harness 接口变化 | Adapter 能力探测、默认拒绝 | 未知版本进入受限模式 |
| Funnel 误开启 | 安装/健康检查阻断和醒目告警 | 检测到公网标记时不通过验收 |
| 恶意更新 | 签名、哈希、版本策略 | 篡改包无法安装 |
| 诊断泄密 | 字段允许列表、本地预览 | 敏感样本测试不进入报告 |

## 11. 上线前安全测试

- 配对码重放、暴力尝试和过期测试。
- 设备撤销、令牌刷新、时钟偏差和并发会话测试。
- 路径穿越、Host Header、WebSocket Origin 和 DNS rebinding 测试。
- 请求重复提交、事件乱序和断线重连测试。
- 安装器权限提升、服务 ACL、目录 ACL 和日志权限测试。
- 更新包替换、降级、回滚和签名失败测试。
- Funnel、公网端口和错误 Serve 目标检测。
